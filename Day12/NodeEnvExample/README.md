## Running The Project
1. Create a file named ".env" file in ./Day12/NodeEnvExample at the same directory level as the package.json.
2. Populate the file with the following text:
```
API_KEY='{YOUR_API_KEY_HERE}'
```

3. Replace `{YOUR_API_KEY_HERE}` with API Key provided in project submission.
4. Ensure version 20 of Node,js (or a compatible version) is installed.
5. Install node modules with the below command.
```
npm i
```

6. Launch the server with the below command:
```
npm run start
```

7. Navigate to `https://localhost:3000` to view page contents.
