## Running The Project
1. Create a file named "env.js" file in ./Day12/VanillaEnvExample
2. Populate the file with the following code:
```
const API_KEY = '{YOUR_API_KEY_HERE}';

export default API_KEY;
```
3. Replace `{YOUR_API_KEY_HERE}` with API Key provided in project submission.
4. Launch page via Live Server extension.
